# naym

## Language

**Couple**:
The two partners naming one baby. Partner A builds the deck; partner B swipes it blind.

**Partner**:
One of the two people on a Shortlist — a lasting identity. Distinct from the per-session roles A (builds the deck) and B (swipes it blind); either partner can be A in a later session.
_Avoid_: user, player

**Shortlist link**:
A partner's private, never-expiring way back to the Shortlist. Each partner has their own; a partner can reissue the other's if it's lost.

**Deck**:
The finite set of name cards both partners swipe in one session, pinned at creation.
_Avoid_: list, pack

**Deal**:
A partner starting a new deck from the Shortlist; the dealer is role A for that session. Seen names are left out; when too few are left, the dealer is asked to add a deck for more. A Shortlist has one live deck at a time.

**Match**:
A name both partners liked in the same deck.

**Shortlist**:
A couple's lasting collection of matches, gathered across all their sessions, that they return to and rank together.
_Avoid_: favorites, list, keepsake

**Duel**:
A private "this or that" choice between two Shortlist names. Each partner's duels build their own ranking; the combined order favors names neither partner ranks low.
_Avoid_: vote, battle

**Seen**:
A name is seen once a deck containing it has been swiped through by both partners. Seen names never return in a new deck, whoever liked them.

**Custom name**:
A name a partner types in themselves. It joins a later deck and reaches the shortlist only if both like it, like any other card. Shown to couples as a "wish"; the card is openly marked as one. Up to three wait in a queue that empties into the next deck either partner deals. A wish spelled like a curated name borrows that card, even if Seen. Wishes take slots of the deck size and count toward the minimum deck, so they can top up a nearly dry pool; the builder's pool shows curated unseen names only, so it never offers a size the deal can't fill.

**Gender tag**:
Each card is tagged girl, boy or unisex as the name is used in that card's culture (the same spelling can differ between decks). A deck is built for "girl", "boy" or "not sure yet"; unisex names belong to all three; wishes carry no tag.

## Relationships

- A **Couple** has one **Shortlist** and many sessions; each session's **Matches** land on it.
- A **Custom name** becomes a card in a later **Deck** — never directly a **Shortlist** entry.

## Flagged ambiguities

- "Favorites" meant both the couple's matches and each partner's own likes. Resolved: the **Shortlist** holds only **Matches**; a partner's private likes never leave the server.
